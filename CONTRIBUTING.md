# Contributing to Recon

Thanks for helping improve Recon. Contributions are welcome—whether you are fixing a bug, improving documentation, adding a detector, or extending the CLI.

Start with the [contributor development guide](docs/development/contributing.md). It covers:

- setting up a development environment
- adding a detector
- adding a CLI command
- writing unit, integration, and semantic tests
- running checks and preparing a change

Please keep changes focused, follow the existing patterns, and include tests for behavior you change. The guide links to the relevant architecture rules as you go.
